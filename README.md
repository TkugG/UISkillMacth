# UISkillMacth — SkillMatch IT Clean Modern Job Portal

> **เว็บรับสมัครงานและจับคู่ทักษะไอทีสมัยใหม่ตามกรอบมาตรฐาน มคอ.2 สาขา IT (TQF:HEd)**  
> ผสานโมเดล Machine Learning จำแนกสายอาชีพ และระบบวิเคราะห์ Skill Gap Analysis จากตำแหน่งงานจริงในไทย

---

## 🌟 จุดเด่นของหน้าจอใหม่ (Modern Job Portal UI/UX)

1. **ดีไซน์ Clean & Professional:** 
   - ออกแบบในสไตล์เว็บรับสมัครงานระดับพรีเมียม (LinkedIn / JobsDB / Linear Aesthetic) 
   - โทนสีขาว คราม และน้ำเงินสะอาดตา (`Slate-50`, `Blue-600`, `Emerald-500`)
   - แสดงสัดส่วน Skill Match Percentage และชิปทักษะที่ตรง (Matched) กับทักษะที่ต้องเติม (Skill Gap) ชัดเจน
2. **ระบบ 2 โหมดในหนึ่งเดียว (Live & Standalone):**
   - **โหมดเชื่อมต่อสด (Live FastAPI):** ตรวจจับและเรียกใช้ API จาก Python Backend (`http://127.0.0.1:8000/recommend`) อัตโนมัติเมื่อเปิดเซิร์ฟเวอร์
   - **โหมดสแตนด์อโลน (Client Engine):** หากยังไม่ได้เปิด Python เซิร์ฟเวอร์ ตัวเว็บจะคำนวณผ่าน Client Engine ในเครื่องได้ทันที 100% โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์
3. **ครบถ้วนตามหลักเกณฑ์วิทยานิพนธ์:**
   - 115 ตำแหน่งงานจริงในตลาดแรงงานไทย
   - 444 ทักษะมาตรฐาน (Canonical Skills) พร้อมพจนานุกรมแปลงคำพ้อง (Synonyms Normalization)
   - 8 กลุ่มอาชีพ มคอ.2 (G1–G8)
   - ปุ่ม Preset ทดสอบด่วนสำหรับกรรมการหรือการนำเสนอโครงงาน 1 คลิก
